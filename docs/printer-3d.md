# 3D 制作台使用与验收

宿主 0.2.2，插件 `community.printer-3d@1.1.0`。这是独立娱乐玩法，不连接真实直播间，不包含平台采集、支付和软件内交易。

## 使用

1. 执行 `devbox run desktop`（已配置原生依赖的 Windows 环境可执行 `pnpm tauri dev`）。
2. 在公共宿主管理中选择“3D 制作台 · 独立娱乐” **1.1.0**，启用后进入 React 专属操作台，再打开展示窗。已有 1.0.0 不自动替换；先处理在制/等待任务，选择新版并启用。旧包按原摘要继续信任。
3. 在“手动制作”填写昵称/文字、作品类型、事件和数量；在“规则演示台”选择测试观众并点击规则按钮。手动提交与模拟提交分别标注来源。
4. 在规则演示台批量导入自有 PNG/JPEG（单次最多 20 张），选择图像后制作；也可在“自有素材与帮助”读取已保存图片。图片经 Rust 解码、缩小、重编码后才可使用。
5. 要声音时，在真实展示窗点击“启用本窗口声音”，控制台取消静音；语音还需启用业务配置中的语音选项。没有可用本地语音时保留字幕。
6. 画面设置可即时调整；业务规则使用“保存并应用到新任务”。旧任务保留接收时的配置、份数和冻结分数。切换插件版本仍需清空在制和等待任务。
7. 控制台可拖动预览调整镜头、保存最多 10 个命名镜头，选择四种输出尺寸。高质量采集对象是独立展示窗，低帧预览不参与制作或播音。
8. 点击“生成规则 PNG”，在控制台检查预览，再选择位置保存。规则文案来自当前配置，不含平台图标与联系方式。

自动演示默认关闭，需显式开启。仅在无在制/等待任务、展示就绪且未暂停时生效，间隔 15–120 秒；重启后关闭。模拟内容不会当作真实平台送礼。重置演示只清理模拟任务/记录，保留手动数据。

## 数据与恢复

- 宿主维护唯一队列，容量按未完成份数计算，最多 100 份；事件数量乘规则份数后超限会整体拒绝。
- 默认优先排队不打断当前。明确选择“受控让位”时保留已完成份和冻结计划，未完成份重新制作，旧 epoch 的回调失效。
- 一份在完整打印和机械臂转运后回执；全部份数完成后任务才结束。成品之后的传送带移动不产生额外业务记录。
- 展示窗丢失、WebGL context lost、系统长时间休眠会记录故障/中断。明确重试时已完成份不重复，分数不重抽。
- SQLite 数据库升级前保留 `*.before-v2-*.sqlite` 备份。回退到旧宿主需使用对应备份；旧宿主不能直接读新版数据库。
- 图片为插件摘要隔离的内容引用，不向插件暴露绝对路径或任意 URL。单次输入图片 8 MiB、最大 4096×4096，导入后最长边 512；每插件最多 200 张且 200 MiB。被任务、命令回执、配置或状态引用的图片不能删除。
- 历史最近 1000 条、每场命令回执最多 10000 条；运行检查点仍有 64 MiB 上限。任务、单元、回执、偏好另有事务一致的查询投影；图片二进制不进入 JSON 检查点。

## 采集与性能

支持 1280×720、1920×1080、720×1280、1080×1920。五档质量、六种抗锯齿和 24/30/60/90/120 FPS 为目标配置，实际以控制台诊断为准；MSAA 按设备能力降级，内部渲染受 8,294,400 像素及 2×倍率预算限制。低帧率只降低内部超采样，不改变外部输出和构图。

Windows 提供固定的软件渲染采集兼容选项，在下次创建展示窗时生效，可通过受控重启应用；不开放任意浏览器启动参数。该选项不代表已经解决所有显卡或直播伴侣的采集问题。

当前已验证真实 Chromium WebGL、冻结计划、暂停、两份有序交付、预览/规则图、场景/抗锯齿切换与旧包兼容。Windows WebView2、NSIS 冷安装、实际声音设备与语音、OBS/直播伴侣、四种尺寸高 DPI，以及 1080p/30 FPS 和连续 30 分钟内存/GPU 资源验收仍需目标机器执行。
